To start, you will need a template that you can edit. Download the template from here or by visting this site's GitHub repo. If you want to check it out live, you can click the example link above.

Once you've' done that, you can start editing! When you open the file, the first thing you'll see is the title. You can either edit this or keep it the same. Just underneath it are the main colours.
