ExamForge Code Help

Each question must be written on a single line and wrapped in < >. Questions are split into four types:

  • True/False
  • Written Question
  • Single Choice
  • Multiple Choice

Rules

  • One question per line
  • No blank lines
  • Text must be in quotes
  • Use ! to mark correct answers

Examples

True / False

<truefalse "The sky is blue" "1">

Written Question

<question "Explain photosynthesis" "Plants use light to make food">

Single Choice

<choice "Capital of France?" "!Paris" "London" "Rome">

Multiple Choice

<multiplechoice "Which are planets?" "!Earth" "Sun" "!Mars">

Common Errors

  • Blank lines
  • Missing quotes
  • No correct answer marked
